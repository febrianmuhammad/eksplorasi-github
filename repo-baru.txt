  Github adalah Layanan Cloud untuk menyimpan dan mengelola project / repository git.
  Version Control System adalah sebuah sistem yang menyimpan rekaman / snapshot perubahan pada source code.
  Git adalah sebuah software untuk mengelola perubahan file dalam folder, riwayat perubahan file disimpan menggunakan serangkaian commit.

Istilah Git
- Repo : folder project kita
- Commit : rekaman / snapshot dari repo kita
- Hash : penanda unik pada sebuah commit
- Checkout : berpindah ke sebuah commit
- Branch : cabang bebas dari sebuah commit
- Merge : menggabungkan branch
- Remote : sumber yang memiliki repo

Branching : 
- Membuat Git Branch
- Membuat snapshot tanpa mengganggu master branch
- Fitur Experimental
- 2 orang mengerjakan repo yang sama
